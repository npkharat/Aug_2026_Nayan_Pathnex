# Parameterized Builds
## Jenkins Pipeline — Parameterized

pipeline{
    agent any
    parameters{
        string( name: 'ENVIRONMENT', defaultValue: 'dev', description: 'Deployment Environment' )
    }
    environment{
        INSTITUTE_NAME = "Pathnex"
    }

   stages{
        stage('Checkout'){
            steps{
                git branch: 'main', url: 'https://github.com/Pathnex/sample-java-app.git'
            }
        }
        stage('Deploy'){
            steps{
                sh'''
                echo "Deploying to $ENVIRONMENT by $INSTITUTE_NAME"
                '''
            }
        }
   }
}

## Ansible — Install Docker

 - name: Install Docker

    - name: install Docker
      yum:
        name: Docker
        state: present
    - name: start Docker
      service:
        name: docker
        enabled: yes
        state: started
